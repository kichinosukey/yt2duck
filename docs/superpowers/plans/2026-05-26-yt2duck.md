# yt2duck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal public-ready Chrome Manifest V3 extension that opens YouTube videos in Duck Player from the right-click context menu.

**Architecture:** The extension uses a background service worker and the Chrome `contextMenus` API. URL parsing is isolated in a pure JavaScript module so it can be unit tested without Chrome APIs.

**Tech Stack:** Chrome Extension Manifest V3, JavaScript ES modules, Node.js built-in test runner, npm scripts.

const YOUTUBE_HOSTS = new Set(["www.youtube.com", "youtube.com", "m.youtube.com"]);

export function extractYouTubeVideoId(value) {
  if (typeof value !== "string" || value.trim() === "") {
    return null;
  }

  let url;
  try {
    url = new URL(value);
  } catch {
    return null;
  }

  if (YOUTUBE_HOSTS.has(url.hostname)) {
    if (url.pathname === "/watch") {
      return nonEmpty(url.searchParams.get("v"));
    }

    const shortsMatch = url.pathname.match(/^\/shorts\/([^/?#]+)/);
    if (shortsMatch) {
      return nonEmpty(shortsMatch[1]);
    }

    return null;
  }

  if (url.hostname === "youtu.be") {
    const id = url.pathname.split("/").filter(Boolean)[0];
    return nonEmpty(id);
  }

  return null;
}

function nonEmpty(value) {
  return typeof value === "string" && value.length > 0 ? value : null;
}
```

Create `src/background.js` with this exact content:

```js
import { extractYouTubeVideoId } from "./youtube.js";

const MENU_ID = "open-in-duck-player";

const YOUTUBE_DOCUMENT_PATTERNS = [
  "https://www.youtube.com/*",
  "https://youtube.com/*",
  "https://m.youtube.com/*",
];

const YOUTUBE_TARGET_PATTERNS = [
  ...YOUTUBE_DOCUMENT_PATTERNS,
  "https://youtu.be/*",
];

chrome.runtime.onInstalled.addListener(() => {
  chrome.contextMenus.create({
    id: MENU_ID,
    title: "Duck Playerで再生",
    contexts: ["page", "link"],
    documentUrlPatterns: YOUTUBE_DOCUMENT_PATTERNS,
    targetUrlPatterns: YOUTUBE_TARGET_PATTERNS,
  });
});

chrome.contextMenus.onClicked.addListener((info) => {
  if (info.menuItemId !== MENU_ID) {
    return;
  }

  const sourceUrl = info.linkUrl || info.pageUrl;
  const videoId = extractYouTubeVideoId(sourceUrl);

  if (!videoId) {
    console.warn("yt2duck: unsupported YouTube URL", sourceUrl);
    return;
  }

  chrome.tabs.create({ url: `duck://player/${videoId}` });
});
```

# yt2duck - YouTube to Duck Player

Open YouTube videos in Duck Player from the Chrome right-click context menu.

## What it does

`yt2duck` adds a `Duck Playerで再生` context menu item on YouTube. When you right-click a YouTube video page or a YouTube video link, it opens a new tab with:

```text
duck://player/<videoId>
```

Example:

```text
https://www.youtube.com/watch?v=Zdzhh_drDhI
duck://player/Zdzhh_drDhI
```

## Supported URLs

- `https://www.youtube.com/watch?v=<id>`
- `https://youtube.com/watch?v=<id>`
- `https://m.youtube.com/watch?v=<id>`
- `https://www.youtube.com/shorts/<id>`
- `https://youtube.com/shorts/<id>`
- `https://m.youtube.com/shorts/<id>`
- `https://youtu.be/<id>`

## Install locally

1. Open `chrome://extensions` in Google Chrome.
2. Enable Developer mode.
3. Click Load unpacked.
4. Select this repository directory.

## Use

1. Open YouTube.
2. Right-click a video page or a video link/thumbnail.
3. Click `Duck Playerで再生`.
4. Confirm Chrome's external protocol prompt if Chrome shows one.

## Development

Run tests:

```bash
npm test
```

## License

MIT
```
